# WTHz-D Alpha releases

Digital in one place. FT8 decoding, maps, propagation & spectrum analysis. In one native Mac workspace.

Public downloads and corresponding source for limited Alpha. Not a general compatibility or production-ready build.

Latest release: [Alpha 3 build 4](https://github.com/mint5auce/wthz-d-releases/releases/tag/v0.1.0-alpha.3), with [publication verification](releases/v0.1.0-alpha.3/VERIFICATION.md).

Requires Apple Silicon and macOS 27.0 or later.
Download the DMG from [Releases](https://github.com/mint5auce/wthz-d-releases/releases), drag WTHz-D into Applications and select Simulator to explore without a radio.
The app cannot tune the radio, assert PTT or transmit.
Experimental Wi-Fi audio and spectrum are included; Wi-Fi FT8 remains disabled.

Every release includes its exact complete corresponding-source archive, release manifest and SHA-256 checksums.
The automatic GitHub source archives for this distribution repository contain only distribution metadata; download the Corresponding-Source asset for the actual application and dependency source.
Project source is GPL-3.0-only; dependency licences and notices are retained in the installed app and corresponding-source packet.

Use [Issues](https://github.com/mint5auce/wthz-d-releases/issues) for problem reports.
Include the version, macOS version, Mac/radio models, connection type and reproduction steps.
Omit credentials, private logs and recordings from public reports.
